# ブレンドシェイプ（シェイプキー）

複数のシェイプキーを組み合わせて新しいシェイプキーを作ったり、値を通常の範囲外に設定したりできます。

---

## 使い方

1. 編集したいメッシュを選択した状態で `Ctrl + Q` でウィンドウを開き、**ブレンドシェイプ** タブを選択します
2. 右の一覧から **ベース** ボタンを押してベースとなるシェイプキーを選びます
3. 組み合わせたいシェイプキーを **追加** ボタンで加えて、数値（-100〜100）を調整します
4. **合成** ボタンを押すとシェイプキーが作成されます

::: tip 上書きをオフにする
デフォルトではベースのシェイプキーをそのまま置き換えます。元のシェイプキーを残したまま新しく作成したい場合は `シェイプキーを上書きする` をオフにしてください。
:::

---

## 使用例

- **シェイプキーを2倍にしたい** — ベースに対象のシェイプキーを選び、さらに同じシェイプキーを追加して合成します
- **顔を改変して干渉してしまっているまばたきを直したい** — まばたきをベースに選び、改変した目の形をマイナス値で追加して合成します
