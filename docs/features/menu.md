# メニュー生成

VRChat 内でアイテムの表示・非表示を切り替えるメニューを、まとめて自動で作成できます。  
[lilycalInventory](https://github.com/lilxyzw/lilycalInventory) を使ったメニュー生成に対応しています。

---

## 開き方

`Ctrl + Q` でウィンドウを開き、**メニュー生成** タブを選択します。

---

## 使い方

1. 探索対象にアバターを登録します
2. 配下のメッシュ（衣装・アクセサリーなど）が一覧表示されます
3. メニューに追加したいメッシュにチェックを入れます
4. **生成** ボタンを押すと [lilycalInventory](https://github.com/lilxyzw/lilycalInventory) 用のメニューがまとめて作成されます

::: tip
VRChat 内で ON/OFF できるようにしたいアイテムだけチェックを入れると、必要なメニューだけ作れます。
:::
