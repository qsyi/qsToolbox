# パッチノート

## v2.1.2

スケール調整モードの「一括同期」を、Modular Avatar本体の処理に委譲するよう変更しました。

### 変更：一括同期をModular Avatar本体の処理に委譲

これまで独自に行っていたボーンのスケール・位置・回転のコピーをやめ、Modular AvatarのMerge Armatureが持つ公式の「ScaleAdjusterを一致させる」「位置をもとアバターに合わせてリセット」と同じ処理を呼び出すように変更しました。より正確なボーン対応付けで同期できます。

あわせて、同期内容を選べる3つのトグル（**ScaleAdjusterを同期** / **スケールを同期** / **回転も同期**、デフォルト全てON）に再編しました。「スケール」または「回転」を同期すると、衣装ボーンの位置も基準アバターに合わせてリセットされます。

[詳しい使い方はこちら →](/features/scale)

## v2.1.1

シェイプキー合成モードの不具合修正と、UIの分かりやすさ改善を行いました。

### 修正：シェイプキー合成でエラーが出て実行できない場合がある

メッシュによっては、合成実行時に `GetBlendShapeFrameVertices() output arrays size must match mesh vertex count` というエラーが出て合成できない不具合を修正しました。

### 改善：「上書き」トグルを分かりやすく

シェイプキー合成モードの **上書き** トグルを **ベースを上書き** に変更し、動作説明のツールチップを追加しました。

## v2.1.0

今回のアップデートでは、顔改変とまばたきの干渉をワンクリックで自動的に直せる新機能「まばたき修正モード」を追加しました。

あわせて、メニュー生成モードとスキャン機能にも改善を加えています。

### 新機能：まばたき修正モード

顔を改変すると、まばたきのシェイプキーと干渉して瞼が突き抜けてしまう問題を、自動的に直せる機能を追加しました。

改変済みの目元シェイプキーとまばたき用のシェイプキーをそれぞれチェックするだけで、補正を焼き込んだ新しいメッシュが生成され、自動的に差し替わります。まばたきと干渉していそうなシェイプキーは自動検出され「候補」バッジが付くので、迷わず選べます。

対応外のアバターや、フェイストラッキングアバターでのまばたき崩れを自力で直したい方向けの機能です。

[詳しい使い方はこちら →](/features/blendshape#まばたき修正モード)

### メニュー生成モード：プレビューをデフォルトONに

メニュー生成モードを開いた時点で、プレビューが自動的にONになるようにしました。チェックを変えるたびにすぐ見た目を確認できます。

[詳しい使い方はこちら →](/features/menu)

### スキャン対象フィルターを追加

ウィンドウ上部の **フィルター** ボタンから、EditorOnly・非アクティブなオブジェクトをスキャン対象に含めるかどうかを選べるようになりました。

## v2.0.0

今回のメジャーアップデートでは、全モードのUIを一から作り直し、UI / UXを大幅に刷新しました。

操作性や視認性が大きく向上し、これまで以上に快適に利用できるようになっています。ぜひ新しくなったqsToolBoxを触ってみてください。

あわせて、マテリアルの影設定を簡単に複数のマテリアルへコピーできる新機能も追加しています‼ ついでに自分が使っている肌マテリアルと衣装マテリアル、逆光ライト設定を同梱しておきました。ぜひ活用してください！

### 新機能：影同期モード

マテリアル設定を簡単にコピーできる「影同期モード」を追加しました。

既存のマテリアルやプリセットから、以下の設定を複数のマテリアルへコピーできます。

- 影（影色のみのコピーにも対応）
- リムシェード
- リムライト
- 逆光ライト
- 距離フェード

また、プリセットを保存して、呼び出せるようになりました。よく使うマテリアル設定はプリセットとして保存できます。さらに、lilToonプリセットをqsToolBoxのプリセットとして読み込むことも可能です。

購入したlilToonプリセットなども、複数のマテリアルへ簡単に適用できます！

[詳しい使い方はこちら →](/features/shadowsync)

### スケール調整モード：愛莉対応

特殊なボーン名を持つ愛莉に対応しました。デカ女でも、これまで通り問題なく利用できます！

[詳しい使い方はこちら →](/features/scale)

### メニュー生成モード：機能改善

Modular Avatarでメニューを管理している方向けに、さらに使いやすくなりました。

生成したメニューのインストール先を指定できるようになり、より柔軟に利用できるようになっています。

[詳しい使い方はこちら →](/features/menu)
