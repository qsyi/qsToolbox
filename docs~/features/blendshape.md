# ブレンドシェイプ（シェイプキー）

シェイプキーに関する2つのモードがあります。まばたきの干渉は **まばたき修正** でワンクリックで自動的に直せます。複数のシェイプキーを組み合わせて新しいシェイプキーを作ったり、値を通常の範囲外に設定したりしたい場合は **シェイプキー合成** を使います。

---

## まばたき修正モード

### こんな時に

- 顔を改変したら、まばたきのシェイプキーと干渉して瞼が突き抜けるようになった
- FaceTracking対応アバターで、まばたきの見た目が崩れる

### 使い方

1. 編集したい顔のメッシュを選択した状態で `Ctrl + Q` でウィンドウを開き、**ブレンドシェイプ** タブの **まばたき修正** サブタブを選択します
2. 右の **まばたきシェイプキー** 一覧から、補正したいまばたき用のシェイプキーにチェックを入れます
3. 左の **改変済み目元シェイプキー** 一覧から、表情改変に使ったシェイプキーにチェックを入れます。まばたきと干渉していそうなものは自動検出され「候補」バッジが付きます
4. **補正を適用** ボタンを押すと、補正を焼き込んだ新しいメッシュが生成され、自動的に差し替わります
5. やり直したい場合は **元メッシュに戻す** ボタンで、適用前の状態に戻せます

::: tip
既に [Avatar Blink Fix](https://booth.pm/ja/items/7074770) に対応しているアバターが数多くあります。この機能は対応外のアバターや、フェイストラッキングアバターなど自力で修正したい方向けです。
:::

---

## シェイプキー合成モード

### こんな時に

- あるシェイプキーの効果を2倍・マイナスにするなど、範囲外の値で使いたい
- まばたき修正では対応しきれない、複雑なシェイプキーの組み合わせを作りたい

### 使い方

1. 編集したいメッシュを選択した状態で `Ctrl + Q` でウィンドウを開き、**ブレンドシェイプ** タブの **シェイプキー合成** サブタブを選択します
2. 右の一覧から **ベース** ボタンを押してベースとなるシェイプキーを選びます
3. 組み合わせたいシェイプキーを **追加** ボタンで加えて、数値（-100〜100）を調整します
4. **合成** ボタンを押すとシェイプキーが作成されます

::: tip 上書きをオフにする
デフォルトではベースのシェイプキーをそのまま置き換えます。元のシェイプキーを残したまま新しく作成したい場合は `シェイプキーを上書きする` をオフにしてください。
:::

### 使用例

- **シェイプキーを2倍にしたい** — ベースに対象のシェイプキーを選び、さらに同じシェイプキーを追加して合成します
