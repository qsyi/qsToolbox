# ブックマーク（BookmarkOverlay）

**シーンビュー**（メイン画面）の上部のバーにボタンが追加され、よく使うフォルダへすばやく移動できるようになります。

---

## ホームボタン

どれだけ深いフォルダにいても、ボタン1つで `Assets` フォルダの先頭に戻れます。

---

## ブックマーク

よく使うフォルダを登録しておくと、ボタン1つで即移動できます。

**登録方法**  
移動したいフォルダを **ブックマークボタン** へドラッグ＆ドロップするだけで登録できます。

**管理方法**  
**ブックマーク管理** を選ぶと、登録済みフォルダの並べ替えや削除ができます。
