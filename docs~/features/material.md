# マテリアル

衣装や髪などのマテリアルを、まとめて差し替えたり変換したりできる機能です。  
**マテリアル置換** と **poiyomi変換** の2つのタブがあります。

---

## こんな時に

- 色違いの衣装マテリアルを、毎回インスペクターで探して差し替えている
- 同じマテリアルが複数のパーツで使われていて、どこで使われているか分からなくなった
- 複数のマテリアルをまとめてPoiyomiシェーダーに変換したい

---

## マテリアル置換

色違いのマテリアルへの入れ替えが手軽にできます。

1. 衣装や髪を選択した状態で `Ctrl + Q` でウィンドウを開き、**マテリアル** タブの **マテリアル置換** を選択します
2. メッシュで使われているマテリアルがサムネイル付きで一覧表示されます
3. 差し替えたいカードに新しいマテリアルをドラッグ＆ドロップするか、右側の欄に直接指定すると切り替わります

### 画面の見方

- 各カードをクリックすると、そのマテリアルを Project ウィンドウでハイライトできます
- 同じマテリアルが複数の場所で使われている場合、代表の1件だけが表示され「+N件」から残りを展開できます

## poiyomi変換

選んだマテリアルをまとめてPoiyomiシェーダーに変換できます。

1. **poiyomi変換** タブを選択します
2. 一覧からliltoonシェーダーのマテリアルにチェックを入れます（liltoon以外はグレーアウトして選べません）
3. 変換先を選びます（`Translate Copy to Poiyomi Pro` / `Translate to Poiyomi Pro` / `Translate Copy to Poiyomi Toon` / `Translate to Poiyomi Toon`）
4. **変換を実行** ボタンを押すと変換されます

`Copy` が付いている方はマテリアルを複製してから変換し（元のマテリアルは残ります）、付いていない方は元のマテリアルを直接書き換えます。

::: warning Poiyomiシェーダーが必要です
このタブはPoiyomiシェーダーがプロジェクトに導入されている場合のみ使えます。
:::
