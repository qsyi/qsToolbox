# マテリアル

衣装や髪などのマテリアルを、まとめて差し替えられる機能です。  
色違いのマテリアルへの入れ替えが手軽にできます。

---

## こんな時に

- 色違いの衣装マテリアルを、毎回インスペクターで探して差し替えている
- 同じマテリアルが複数のパーツで使われていて、どこで使われているか分からなくなった

---

## 使い方

1. 衣装や髪を選択した状態で `Ctrl + Q` でウィンドウを開き、**マテリアル** タブを選択します
2. メッシュで使われているマテリアルがサムネイル付きで一覧表示されます
3. 差し替えたいカードに新しいマテリアルをドラッグ＆ドロップするか、右側の欄に直接指定すると切り替わります

## 画面の見方

- 各カードをクリックすると、そのマテリアルを Project ウィンドウでハイライトできます
- 同じマテリアルが複数の場所で使われている場合、代表の1件だけが表示され「+N件」から残りを展開できます
