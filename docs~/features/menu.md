# メニュー生成

VRChat 内でアイテムの表示・非表示を切り替えるメニューを、まとめて自動で作成できます。  
[Modular Avatar](https://modular-avatar.nadena.dev/ja) のメニューと、[lilycalInventory](https://github.com/lilxyzw/lilycalInventory) の Item Toggler を組み合わせて生成します。

---

## こんな時に

- 衣装や装飾パーツを増やすたびに、メニューのトグルを手作業で1つずつ作っている
- とりあえず「オンオフだけできればいい」メニューをサクッと作りたい

---

## 使い方

1. 衣装やアクセサリーを選択した状態で `Ctrl + Q` でウィンドウを開き、**メニュー生成** タブを選択します
2. 配下のメッシュが一覧表示されるので、メニューに追加したいものにチェックを入れます
3. 上部の **フォルダ名** に生成するメニューフォルダの名前を入力します（未入力ならアバター名などが自動で入ります）
4. 必要なら **プレビュー** ボタンでチェック済みのメッシュを一時的に非表示にして、見た目を確認できます
5. **生成** ボタンを押すと設置先を選ぶウィンドウが開くので、置きたい場所を選んで生成します

::: tip
この機能は簡易的なものです。グループ分けや細かい設定など、より複雑なメニューを作りたい方は [lilycalInventory](https://github.com/lilxyzw/lilycalInventory) を直接操作するのがおすすめです。
:::

## 画面の見方

- **全選択 / 全解除** — 一覧のチェックをまとめて切り替えます
- **プレビュー** — チェック済みのメッシュを一時的に非表示にします。もう一度押すか、生成・チェック変更で自動的に元に戻ります
- 各行をクリックすると、そのメッシュを選択してハイライトできます

## 設置先の選び方

**生成** を押すと出てくるウィンドウで、メニューをどこに置くか選べます。

- **ルート（指定しない）** — 今まで通りアバター直下に生成します
- 既存の階層に表示される **フォルダ** — 選ぶとそのフォルダの中に直接生成されます
- 既存の **メニューアセット**（`VRCExpressionsMenu`）— 選ぶとアバター直下に生成した上で、そのメニューアセットへ差し込まれます

行は1回クリックで選択、もう一度クリックするか下部の **生成** ボタンを押すと確定します。何も選ばずに **生成** を押すとルートとして扱われます。深い階層は初期状態で折りたたまれているので、▶ をクリックして開いてください。

生成が終わると、作成したフォルダが選択された状態でハイライトされます。
