# 影同期

体・顔・衣装・髪などでマテリアルが分かれていると、影の色や強さがパーツごとにバラバラになりがちです。  
この機能では、コピー元にしたマテリアルの lilToon 影設定を、他の複数マテリアルへまとめて同期できます。

---

## こんな時に

- 体の影は良い感じなのに、衣装や髪の影だけ色が浮いている
- 逆光ライトやリムライトを全パーツに揃えたいけど、ひとつずつ設定するのが大変
- 「肌用」「衣装用」のような自分の定番設定を、プリセットとして使い回したい

---

## 使い方

1. コピー先にしたいマテリアルが入っているオブジェクトを選択した状態で `Ctrl + Q` でウィンドウを開き、**影同期** タブを選択します
2. 上部の **コピー元** にマテリアルをセットします（直接選ぶほか、レンダラーやオブジェクトをドラッグ＆ドロップでも可。下の **プリセット** から選ぶこともできます）
3. コピーしたい項目にチェックを入れます（後述）
4. 右側の **コピー先** マテリアルにチェックを入れます
5. 下部の **同期** ボタンを押すと、チェックした項目だけがコピー先へ反映されます

::: tip
コピー元と同じシェーダー・同じ設定を使っていない項目（コピー元にそのプロパティが存在しない）はチェックできません。
:::

## 画面の見方

### コピー元カード

- マテリアルをセットすると、影色などのスウォッチが各項目見出しに表示されます

### コピー項目

左側にカテゴリごとの見出しがあり、見出し左のチェックボックスでカテゴリ丸ごとON/OFFできます。

- **全項目を同期** — 一番上のマスタートグル。全カテゴリを一括ON/OFFします
- **影** — 影色1〜3・境界色と、境界・ぼかし・法線強度などの数値項目。クリックで展開できます
- **リムシェード / リムライト / 逆光ライト / 距離フェード** — それぞれ単一チェックボックスで、その系統の項目をまとめてON/OFFします（個別のON/OFFはできません）

スウォッチ右下の数字は不透明度（%）です。リムライトには合成モード（通常/加算/スクリーン/乗算）、逆光ライトには発光強さのバッジが付きます。

### 色相・彩度スライダー

左下の **色相** ・ **彩度** スライダーで、同期する色味をまとめて調整できます。コピー元の色そのものは変更されません。中央付近にドラッグすると自動でリセット値（±0 / ×1.0）にスナップします。

## プリセット

コピー元を毎回選ばなくても、あらかじめ保存した設定をプリセットとして使えます。

- **選ぶ** — カードをクリックすると選択され、そのプリセットの項目だけがチェックされた状態になります。もう一度クリックで選択解除
- **保存する** — コピー元マテリアルを選んだ状態で、フッターの **プリセット保存** ボタンから保存ウィンドウを開きます。保存する項目だけを個別にチェックでき、分類（カテゴリ）も指定できます
- **リネーム・削除** — 保存したプリセットを右クリックすると「名前を変更」「削除」が選べます

::: tip
プリセットはカテゴリごとに折りたたんで表示されます。見出しをクリックすると開閉できます。
:::
