## 具体的に何が変わるの？

- **Ctrl + E** — 選んだオブジェクトをすぐ EditorOnly / 非表示に切り替え。作業中に邪魔なパーツをサッと隠せます
- **Ctrl + Q** — 選択中の衣装やオブジェクトに使えるツールをまとめて呼び出し。マテリアル差し替え・スケール同期・ブレンドシェイプ編集などが一か所に
- **右クリックメニュー** や **シーンビュー上部のバー** にも機能を追加。よく使うフォルダへのブックマークや、ルートへのコンポーネント一括追加もできます
